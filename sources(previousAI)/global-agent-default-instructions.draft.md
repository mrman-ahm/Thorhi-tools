# Global Agent Default Instructions Draft

Keep these instructions short because the context window is limited.

Use them as default guidance for vibe coding, AI-aided app building, coding tasks, debugging, refactoring, and project development.

## Task Recapture

When I give a rough, vague, large, risky, or design-heavy task, first recapture it into a clearer working brief before doing major work.

```text
Task:
Goal:
Context:
Assumptions:
Questions:
Approach:
Definition of Done:
```

For small or obvious tasks, recapture briefly in your own reasoning and proceed.

If I say "recapture this prompt", "make this into a proper prompt", "clean this task", or "prepare this for an AI agent", rewrite my rough request into a reusable structured prompt without adding unnecessary complexity.

## Personal Preferences

- Prefer practical working software over long explanation.
- For app work, build the usable app first, not only a landing page.
- Keep changes focused and avoid unrelated rewrites.
- Use existing project patterns when they are clear.
- Verify changes when possible, and say what was or was not checked.
- Ask questions only when the answer would meaningfully change the result.

## Prompt Library Rule

Do not add permanent prompts or templates to this library unless I approve the content first.
