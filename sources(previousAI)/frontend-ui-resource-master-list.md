# Frontend UI Resource Master List

> A reusable directory of **133 frontend component, block, animation, template, theme, shader, and design-system resources** gathered during the research conversation.
>
> Last organized: 22 July 2026.

## Instructions for an AI agent

- Use this file as a **resource pool**, not as permission to combine every library in one project.
- First inspect the project's framework, Tailwind version, React/Next.js version, accessibility requirements, and existing design system.
- Prefer the official installation or registry method when available. Copy only the components actually needed.
- Restyle imported components so typography, spacing, radii, borders, motion, and colors remain consistent across the website.
- Check licensing, maintenance status, dependencies, mobile behavior, accessibility, and performance before production use.
- Never copy paid or restricted source code without an appropriate license.

## Recommended selection rule

For most projects, choose:

1. One structural foundation, usually **shadcn/ui**.
2. One main block or template source.
3. One motion or visual-effects source.
4. One theme system.
5. Specialized libraries only for specific product requirements.

## Final implementation warning

These resources should help an AI discover strong components and implementation patterns. They should **not** replace deliberate art direction. The AI should evaluate each candidate, use only the best-fitting pieces, and rebuild or adapt them into one coherent visual system rather than producing a collage of unrelated libraries.
